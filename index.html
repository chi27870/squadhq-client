SquadHQ client mod

Optional mod for the SquadHQ server. It shows dyed chests and barrels, chests and barrels on animals, and the backpack slot. Players without it can still join.

Minecraft 26.3 · Fabric Loader 0.20.1 · Fabric API 0.166.2+26.3 · Java 25

Download pack (.mrpack) Download zip

Easiest: Prism Launcher or Modrinth App

  1. Install Prism Launcher or the Modrinth App (both free).
  2. Download the .mrpack above.
  3. In the launcher, add an instance by importing that file. It sets up Minecraft 26.3, Fabric and the mod for you.
  4. In Prism, make sure the instance uses Java 25.
  5. Launch it and join the SquadHQ server.

Regular Minecraft launcher

  1. Install Fabric Loader 0.20.1 for 26.3 with the Fabric installer.
  2. Download Fabric API 0.166.2+26.3.
  3. Unzip the zip and put squadhq-client-1.0.0.jar from its mods folder, plus the Fabric API jar, into .minecraft\mods.
  4. Launch the Fabric 26.3 profile and join the server.
